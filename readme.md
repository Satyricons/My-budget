# 💰 My Budget — веб-приложение для семейного бюджета

Веб-приложение для управления семейным бюджетом на основе Google Таблиц.

## 🚀 Возможности

- 📊 Просмотр текущего баланса, долга и других показателей
- ➕ Пополнение бюджета
- ➖ Снятие средств
- 🔄 Автоматическое обновление данных
- 📅 История транзакций с датой и временем
- 📈 Накопительный расчёт долга

## 🛠️ Технологии

- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Backend**: Google Apps Script
- **База данных**: Google Sheets
